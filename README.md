# EcoTrack Explorer

## Deskripsi Singkat Proyek
**EcoTrack Explorer** adalah media interaktif berbasis model *Game Based Learning* yang dirancang sebagai sarana pembelajaran IPA pada materi **Keseimbangan Ekosistem**. Media ini dapat digunakan oleh guru dan peserta didik untuk belajar dengan cara yang menyenangkan dan interaktif.

## Fitur Utama
- **Petunjuk Penggunaan**: Panduan untuk guru dan peserta didik agar mudah menggunakan media ini.
- **Materi Edukasi**: Pembahasan materi keseimbangan ekosistem yang disajikan secara menarik.
- **Permainan Edukatif**: Permainan digital *EcoTrack Explorer* dengan model permainan ular tangga untuk memperkuat pemahaman materi.

## Cara Menjalankan
- Dapat diakses melalui **GitHub Pages** (jika dihosting).
- Dapat dijalankan pada perangkat **Android** menggunakan browser atau aplikasi yang mendukung format `.swf` (misalnya melalui **Ruffle emulator** jika Flash tidak didukung).

## Teknologi yang Digunakan
- Adobe Animate
- SWF (Flash)
- HTML
- Ruffle (untuk emulasi SWF di browser modern)
- Android (untuk akses melalui perangkat mobile)

## Pembuat / Tim
Media interaktif **EcoTrack Explorer** dikembangkan oleh **Eva Purnamawati**.  
Game ini mengadaptasi permainan ular tangga digital dari situs **wandah.com** dan dikembangkan lebih lanjut sebagai media pembelajaran IPA.
